# shabbat-yerucham

זמני כניסת ויציאת שבת בירוחם — אתר PWA (`docs/`) ואפליקציית Expo (`mobile/`).

האתר מתפרסם דרך GitHub Pages מתוך תיקיית `docs/`.

## ה-PWA

`docs/` הוא Progressive Web App מלא: אפשר להתקין אותו למסך הבית באנדרואיד
ובאייפון, והזמנים נטענים גם בלי אינטרנט.

| קובץ | תפקיד |
| --- | --- |
| `docs/manifest.webmanifest` | שם, אייקונים, צבעים ומסך פתיחה |
| `docs/sw.js` | Service worker — קאשינג של הדפים, הגופנים וקובץ הזמנים |
| `docs/app.js` | רישום ה-SW, פופאפ ההתקנה וטופס ההרשמה לבודקים |
| `docs/form-config.js` | כתובת טופס ההרשמה — הקובץ היחיד שצריך לערוך |
| `docs/icons/` | אייקונים 192/512, maskable ו-apple-touch |

הדפים עצמם:

| דף | תוכן |
| --- | --- |
| `docs/index.html` | בית — זמני השבת הקרובה ושלוש השבתות שאחריה |
| `docs/times.html` | טבלת הזמנים המלאה, כולל שקיעה ורבנו תם |
| `docs/about.html` | אודות — מה האפליקציה, מקור הזמנים, התקנה והבהרה |
| `docs/privacy.html` | מדיניות פרטיות |
| `docs/terms.html` | תנאי שימוש |

### אייקונים

האייקונים בדפים הם SVG מוטמע: כל דף נושא בראש ה-`<body>` ספרייט `<symbol>`
אחד, והשימוש נעשה דרך `<svg><use href="#i-home"/></svg>`.

קודם לכן שימש Material Symbols של גוגל, ושם זו הייתה טעות: הפונט ההוא עובד
בליגטורות — בקוד כתובה המילה `light_mode` והפונט מחליף אותה בציור. כשהפונט
לא נטען, מה שנשאר על המסך הוא המילה עצמה. ההגדרה `display=swap` שבקישור אף
הבטיחה שהמילה תוצג מיד בכל טעינה איטית, ובביקור ראשון בלי רשת היא נשארה שם.
באפליקציה שאמורה לעבוד אופליין זו תלות במקום הלא נכון, ולכן היא הוסרה.

הוספת אייקון = הוספת `<symbol>` לספרייט בכל דף שצריך אותו. הצורות מצוירות
ידנית ואינן זהות לאייקונים של Material.

### עמוד אודות

`about.html` בנוי מהשלד של `times.html`, כדי שהכותרת, הפוטר והניווט יישארו
זהים בין הדפים. כל שינוי בניווט צריך להיעשות בשניהם.

התוכן שם נשען על מה שכבר מתועד בריפו ולא מוסיף עליו: שהזמנים מועתקים מלוח
הרב אודי רט ואינם מחושבים באפליקציה, שהם לירוחם בלבד, ושבמקרה של ספק
מכריעים לפי הלוח המודפס ולפי רב הקהילה. **אין לנסח שם קביעות הלכתיות
חדשות** — הלוח הוא המקור, והעמוד רק מפנה אליו.

הקישור "כיצד מחושב?" בתחתית `times.html` מצביע לעמוד הזה (`about.html#how`
כעוגן זמין), וכך גם "אודות" בתפריט העליון ובניווט התחתון של כל דף.

### פופאפ ההתקנה

- **אנדרואיד / Chrome** — נתפס אירוע `beforeinstallprompt`, ואחרי 2.5 שניות
  עולה כרטיס תחתון עם כפתור "התקנה" שמפעיל את הדיאלוג המקורי.
- **iOS / Safari** — שם אין `beforeinstallprompt`, ולכן מוצגות הוראות
  ("שיתוף ← הוספה למסך הבית"), ורק החל מהביקור השני באתר.
- סגירה או "לא תודה" משתיקים את הפופאפ ל-7 ימים (`localStorage`).

### טופס ההרשמה לבודקים

מי שכבר התקין את ה-PWA (הדף רץ ב-`display-mode: standalone`) מקבל אחרי
4 שניות הזמנה להירשם כבודק/ת לאפליקציית האנדרואיד. בנוסף יש קישור קבוע
בפוטר של כל דף — כל אלמנט עם התכונה `data-sy-tester` פותח את אותו טופס.

הטופס עצמו הוא Google Form שאוסף כתובת ג'ימייל אחת. זו הכתובת שמודבקת
ל-Play Console תחת Closed testing ← Testers ← Email list.

הטופס נפתח בלשונית חדשה (לא מוטמע), ולכן כל שירות טפסים מתאים. **כדי להחליף
אותו**, ערכו שורה אחת ב-`docs/form-config.js`:

```js
window.SY_TESTER_FORM_URL = 'https://forms.gle/UZ7UUn7BD6WeUqfg6';
```

הטופס נפתח ב-iframe בתוך מודאל מעוצב, כך שאין צורך במפתחות API בקוד הציבורי.
כל עוד המשתנה ריק, הכפתור נופל בחזרה למייל מוכן מראש (`FALLBACK_EMAIL`).

### עדכון גרסה

אחרי שינוי בקבצי האתר, העלו את `VERSION` ב-`docs/sw.js` כדי לפנות את הקאש
הישן אצל מי שכבר התקין.

### האייקון

`docs/icons/source-icon.png` (512×512) הוא המקור — פסל הזהות של ירוחם על
רקע השמש, אותו אייקון שבחנות. כל שאר הקבצים נגזרים ממנו, כולל גרסת
ה-maskable: המסכה העגולה של אנדרואיד חותכת רק שמיים ואת שולי הגבעה,
והשמש והפסל נשארים שלמים, ולכן אין צורך בהקטנה ל-safe zone.

אחרי החלפת המקור צריך לייצר מחדש את ה-PNG-ים ולהעלות את `VERSION`
ב-`sw.js`, אחרת מי שכבר התקין יישאר עם האייקון הישן בקאש.

האפליקציה ב-`mobile/` עדיין משתמשת באייקון ברירת המחדל של Expo.

### תצוגה מקדימה ברשתות ואנימציית השקיעה

כל חמשת הדפים נושאים תגי Open Graph ו-Twitter Card
(`og:title`, `og:description`, `og:image`, `twitter:card=summary_large_image`),
כך שקישור לאתר מוצג בוואטסאפ, בפייסבוק ובטוויטר עם כרטיס תמונה גדול.
הכתובות ב-`og:` הן **מוחלטות** — רשתות חברתיות לא פותרות נתיבים יחסיים.
אם הדומיין ישתנה צריך לעדכן אותן בכל חמשת הדפים.

| קובץ | תפקיד |
| --- | --- |
| `docs/icons/og-image.png` | כרטיס ה-preview (1200×630) |
| `docs/icons/sunset.gif` | אנימציית השקיעה (יום ← לילה, 256×256) — בראש `about.html` |

הגיף מוצג בראש `about.html` בלבד — בעמוד הבית הוא דחק את הזמנים, שהם הסיבה
שפותחים את האפליקציה, אל מתחת לקפל. מי שהגדיר `prefers-reduced-motion: reduce`
מקבל במקומו את אייקון האפליקציה הסטטי. שני הקבצים נמצאים ב-precache.

שימו לב: וואטסאפ, פייסבוק וטוויטר אינם מנפישים GIF ב-preview אלא מציגים
תמונה סטטית, ולכן הכרטיס הוא `og-image.png` — פריים דמדומים מתוך אותה
אנימציה — ולא הגיף עצמו.
